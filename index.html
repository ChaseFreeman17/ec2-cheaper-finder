EC2 Undercut

Pick a region, enter an EC2 instance type, and we'll find current-generation types with at least as much vCPU & RAM that cost less On-Demand in that region — and flag what else changes along the way, including any extra CPU/RAM you're getting.

ⓘ

Family (first letter)

  • M — General purpose
  • C — Compute optimized
  • R — Memory optimized
  • X — Extra memory optimized (very high RAM per vCPU)
  • T — Burstable, credit-based
  • I — Storage (I/O) optimized, local NVMe
  • D — Dense HDD storage optimized
  • Z — High frequency + high memory
  • G / P — GPU-accelerated (excluded from this tool)
  • F — FPGA-accelerated (excluded from this tool)
  • Hpc — High performance computing

Suffix after the generation number

  • g — AWS Graviton (ARM) processor
  • i / a — Intel / AMD processor
  • n — Enhanced networking
  • d — Local NVMe SSD storage included
  • flex — Flexible baseline/burst compute
    One instance type per line — optionally add a count, e.g. m5.xlarge,12 (a plain list of types, one per line, still works too — count then defaults to 1).

    Shows current-generation instance types meeting these minimums, cheapest first — with no baseline to compare against, nothing is flagged as a "change."
